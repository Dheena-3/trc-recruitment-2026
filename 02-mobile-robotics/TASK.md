## Rules

1. Use meaningful names for inputs and outputs.
2. **Everyone must complete Level 1, Task 1A.** It is compulsory for interview selection.
3. It is highly preferred to avoid AI wherever possible, especially when writing code.

## What to put in this folder

Follow the deliverables listed in the task document. Put everything for a task in its own folder:

```
02-mobile-robotics/
├── TASK.md                 <- this file, don't edit
└── level-1-we-bots/
    └── task-1a/            <- your code, world/project files and screenshots for Task 1A
```

Add further task folders under `level-1-we-bots/` (for example `task-1b/`) if you attempt more tasks.
