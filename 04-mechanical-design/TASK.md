There are two levels:

Each task is provided as a tab in the Google Docs below.

## Rules

- Fusion 360 is recommended, since most resources are tailored for it. If you can't use it, discuss alternatives with your mentor.
- Submission is done on GitHub, with the design file and a screenshot for each task.

**Note:** if you choose this domain together with Mobile Robotics, Electronics is not mandatory.
Interested students can attempt all domains.

## What to put in this folder

For every task, commit the design file and a screenshot of it:

```
04-mechanical-design/
├── TASK.md                 <- this file, don't edit
├── level-1/
│   ├── task-0/             <- design file + screenshot
│   └── task-1a/
└── level-2/
    ├── task-1b/
    └── bonus/              <- optional
```
