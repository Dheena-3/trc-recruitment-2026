# 01 – GitHub: Git Fundamentals

Complete the exercises on **[Git Exercises](https://gitexercises.fracz.com/)**.

## Tasks

1. Complete **all exercises from Level 1 to Level 10** (feel free to finish all 23).
2. Take a **screenshot of the completed progress page** and add it to `screenshots/`.
3. Add an **`exercise_<no>.md`** describing:
   - What each exercise taught you (2–3 lines each)
   - Commands you learned and answered
   - Challenges you faced

Use [`exercise_template.md`](exercise_template.md) as the starting point.

## What to put in this folder

```
01-github/
├── TASK.md                 <- this file, don't edit
├── exercise_template.md    <- copy this for each exercise
├── exercise_1.md           <- yours
├── exercise_2.md
├── ...
└── screenshots/
    └── progress.png        <- screenshot of the completed progress page
```

## Checklist

- [ ] Levels 1–10 completed (bonus: all 23)
- [ ] Progress-page screenshot added to `screenshots/`
- [ ] `exercise_<no>.md` written for each exercise
- [ ] Each file covers what it taught you, commands learned, challenges faced
- [ ] Everything committed and pushed
- [ ] Mentors added as collaborators
